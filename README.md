# AgentSchool

A polished MVP dashboard for an AI agent learning and certification platform.

## What is included

- Dashboard with mastery, certifications, milestones, and activity
- Learning path with three starter courses
- Skill matrix for Agent Alpha
- Interactive final exam modal with answer validation
- Certification-ready exam flow and progress UI
- Responsive layout for desktop, tablet, and mobile

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

This first slice is frontend-only. The next production layer can connect users, agents, lessons, attempts, and certificates to PostgreSQL/Prisma and an AI grading service.
