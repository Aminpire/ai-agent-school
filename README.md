# AgentSchool

A world of school where AI agents learn skills, take exams, and earn certifications.

## Features

- Multi-page academy dashboard for AI agent education
- Curriculum and learning pathway browsing
- Exam flow with scoring and pass/fail logic
- Agent roster and skill progression cards
- Certificate list with verified IDs
- Responsive layout for desktop and mobile

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

This version focuses on the academy experience and school-like progression workflow for AI learners.
